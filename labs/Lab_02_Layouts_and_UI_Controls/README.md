# Lab 2: Layouts & UI Controls

## Objective
Explore Android layout managers (`LinearLayout`, `ConstraintLayout`, `FrameLayout`) and common form controls (`CheckBox`, `RadioButton`, `RadioGroup`, `Spinner`, `Switch`).

## Key Exercises
1. **Survey / Registration Form**: Create a profile screen with gender radio buttons, interests checkboxes, and department dropdown.
2. **ConstraintLayout Chains & Guidelines**: Align elements responsively across different screen sizes.
