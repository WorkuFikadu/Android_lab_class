# Lab 1: My First Android App

## Objective
Learn the fundamentals of Android Studio, project setup, XML layouts, View binding via `findViewById`, and basic event handling (`OnClickListener`).

## Core Concepts Covered
1. **Activity Lifecycle**: Understanding `onCreate(Bundle savedInstanceState)`
2. **View Inflation**: Linking XML layout using `setContentView(R.layout.lab_demo)`
3. **User Interaction**: Listening for button clicks and reading text from `EditText`
4. **User Feedback**: Showing short and long `Toast` messages and updating `TextView`

## Solution Code
See:
- Java: `app/src/main/java/com/example/android_lab_class/MainActivity.java`
- Kotlin: `app/src/main/java/com/example/android_lab_class/MainActivityKotlin.kt`
- Layout: `app/src/main/res/layout/lab_demo.xml`
