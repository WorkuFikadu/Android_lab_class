# Lab 5: Lists with RecyclerView & Custom Adapters

## Objective
Build smooth, high-performance scrollable lists using `RecyclerView`, custom `ViewHolder`, and `RecyclerView.Adapter`.

## Key Exercises
1. **Model & Item Layout**: Define a `Student` or `Task` data model with item card XML.
2. **Adapter & ViewHolder**: Implement `onCreateViewHolder`, `onBindViewHolder`, and `getItemCount`.
3. **Item Click Listeners**: Open a detail screen when an item in the list is clicked.
4. **Swipe to Delete / Item Touch Helper**: Add gesture interactions.
